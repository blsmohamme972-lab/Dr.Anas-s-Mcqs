## Book-level notes

- Not yet medically reviewed: no explanations; answer keys are as in the source unless a question note says the key was added by the editor; topics were assigned by keywords and then a manual pass over every question stem, and should be confirmed during medical review.
- This is a mixed cardiothoracic book: questions are filed under cardiac, thoracic or (a few) vascular topics according to what each stem tests; the book's own specialty is set to cardiac only for the cover colour.
- The source is 1,619 app screenshots read by OCR; the source has no question numbers, so questions are numbered 1–836 in page order.
- 109 questions have no key in the source (only the reader's own ticked choice). Each was given a key by the editor (see the question notes); these keys must be confirmed during medical review.
- Q111, Q696, Q702, Q739 and Q818: option A is scrolled out of view in every screenshot, so only the source's options B–E are shown; in the app they appear as A–D, and the key was moved with them (e.g. source C → app B).
- Many screenshots are cut off by scrolling; where an option or stem is incomplete in the source this is noted on the question (see the extraction report on Drive).
